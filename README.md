## ✨ What this project does

Project-NFC-HUNT is a personal NFC identity landing page built for one purpose: when someone taps an NFC-enabled card against a phone, they get instant access to my digital profile.

It is designed to work as a smart digital business card and personal contact hub with:

- a premium personal profile card layout
- direct links to website, GitHub, social channels, and contact options
- quick actions for phone, WhatsApp, and email
- a share/copy interface for fast profile distribution
- responsive modern styling for mobile and desktop
- a sleek tech aesthetic suited for professional and personal NFC card use

This is not just a static page — it is a practical NFC-friendly identity page made for linking custom cards to my online presence.

---

## 🧩 Core features

- NFC-ready personal profile page for scanning from ID cards
- One-tap access to social profiles, portfolio, and contact methods
- Share/copy link feature for easy profile distribution
- Quick access buttons for calls, WhatsApp, and email
- Lightweight front-end built with vanilla HTML, CSS, and JavaScript
- Clean responsive UI that feels premium and professional
- Easy deployment to GitHub Pages or static hosting for card URL linking

## 🚀 Quick start

1. Clone the project
   ```bash
   git clone https://github.com/XexanTerxcin/Project-NFC-HUNT.git
   ```
2. Open the project folder
   ```bash
   cd Project-NFC-HUNT
   ```
3. Launch the homepage locally
   ```bash
   start index.html
   ```
4. Use the page as the target URL for your NFC card
   - Write the project URL to your NFC card
   - The card opens this profile page instantly
   - Visitors can view portfolio, socials, and contact options instantly

> This project is intended to be used as the landing destination behind an NFC-enabled personal ID card or smart business card.
